## 로컬 자동 검증

- npm run typecheck 통과.
- npm test: 17개 파일, 272개 테스트 통과. 기존 250개 유지, 출력·해석·보고서·예제 22개 추가.

- CSV BOM·쉼표·줄바꿈·정밀도·수식 문자열 보호·숫자 음수, XLSX 숫자/문자/불리언 및 수식 없음 검증.
- 전체/필터/선택/정렬/페이지 독립 출력, 분석 지표·행·연관 계수, HTML escaping/CSP·고정 시점·한도, JobGate 취소·이전 응답 차단 검증.
- 네 예제: 월별 6/10, 생성식 계수 3/2/−4, SSE=1과 실루엣, 6거래 복합 규칙을 독립 정답과 비교.

- 4개 예제 사본 열기, 저장된 결과·최신 상태·예시 해석 표시.

## 성능·제한

초기 구현 main 641KB / Worker 688KB에서 파일 파서와 검증 모듈 분리 후 main 약609KB / 기본 Worker160KB. XLSX499KB와 차트629KB는 필요 시 로드합니다. 전체 precache에는 포함합니다. Vite 500KB 경고는 남아 있으며 임계값을 올려 숨기지 않았습니다. 학교 PC의 실제 성능은 미측정입니다.

사용자 데이터는 외부로 전송하지 않습니다. 브라우저별 다운로드·인쇄·설치 지원은 다릅니다. 큰 범위는 명시적 한도로 차단하며 전체 파일 복원은 JSON 백업을 사용합니다.
