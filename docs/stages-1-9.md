# 데이터뜰 — 9단계: 연관 규칙·거래 근거·조건 비교

고등학생과 교사를 위한 React·TypeScript·Vite 정적 웹앱입니다. 다섯 메뉴와 한국어 화면, 1단계의 원본·버전·작업 기록 구조를 유지합니다. 파일은 기기 안에서 처리하며 업로드 API, 런타임 CDN, 외부 폰트, 로그인은 사용하지 않습니다.

## 실행과 검증

Node.js 22.12 이상 또는 24 LTS를 사용합니다.

```sh
npm ci
npm run dev
```

기본 주소는 http://127.0.0.1:5173 이며, 사용 중이면 터미널에 다른 포트가 표시됩니다.

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/`가 정적 빌드 결과입니다. `base: './'`를 유지하여 저장소 하위 경로에 대비했습니다. PWA manifest와 빌드 산출물 전체를 미리 저장하는 Service Worker를 포함합니다. 실제 배포는 하지 않았습니다. 개발 서버에는 Service Worker를 등록하지 않습니다.

검증 자료는 `tests/fixtures/`에 있습니다. `node scripts/create-fixtures.mjs`로 일반 검증용 CSV·XLSX를 다시 만들 수 있습니다. `cancel-large.csv`는 한도에 가까운 49,999행·10열 검증 자료입니다.

## 유지한 1·2단계 기능

- **파일 열기:** CSV의 UTF-8/BOM·EUC-KR/CP949, 쉼표·세미콜론·탭·파이프 구분자, 첫 행 열 이름 여부. 인코딩은 명시적으로 선택하며 BOM은 자동 처리합니다.
- **XLSX:** 시트 목록과 시트 선택, 실제 값·표시 문자열·날짜/앞자리 0 형식 고려 중 값 기준 선택. 숫자·문자·불리언·날짜·빈 셀을 처리합니다.
- **확정 전 미리보기:** 앞 10행과 전체 행 수, 각 열의 저장형·의미·분석 사용 여부. 열을 선택해 이름·유형·설명을 수정할 수 있습니다. 보정과 변환 안내 확인 후에만 ‘불러오기’가 활성화됩니다.
- **보존:** 새 자료 ID로 등록하며 같은 파일도 덮어쓰지 않습니다. 파싱한 원본 값·최초 열 정보·XLSX 셀 표시/형식 메타데이터를 보존합니다. 최초 입력 버전과 자료형 적용 버전을 별도로 만들고 입력 조건과 계보를 기록합니다.
- **편집:** 셀 값을 누르거나 오른쪽 ‘속성 편집’을 사용합니다. 확정/취소가 있고, 검증 실패 시 값과 버전을 유지합니다. 실제 변경만 새 버전과 작업 기록을 만들며 행·열 ID는 유지합니다.
- **탐색:** 열 기준 정렬, 저장형에 맞는 필터, 행·열 다중 선택, 25/50/100행 페이지 분할. 전체 행·조건 일치 행·현재 페이지 행을 구분합니다. 필터로 숨겨진 선택도 유지합니다.
- **확인:** 전체/필터 자료 기준의 결측·고유값, 수치 통계, 범주별 빈도(20개씩), 중복 집단·해당 행·추가 중복 수와 중복 행만 보기.
- **작업 제어:** 파일 읽기·파싱·등록 검증·편집 검증·통계/정렬/필터/중복 계산을 Worker에서 처리합니다. 진행 단계와 취소, 원인/해결 방법을 표시합니다. 측정할 수 없는 백분율을 만들지 않습니다.
- 메뉴를 이동해도 현재 자료, 속성, 정렬·필터·선택·페이지·표 간격을 유지합니다. 설정 패널은 접을 수 있고 좁은 화면에서는 아래로 이동합니다.

## 데이터 처리 기준

- 결측은 **null과 빈 문자열(`''`)**만 해당합니다. 공백, `NA`, `0`, `false`는 값으로 보존합니다. 숫자·불리언 변환에서 빈 문자열은 명시된 결측 기준에 따라 null로 저장하며 원본 빈 문자열은 유지합니다.
- CSV는 자동 숫자 변환 없이 문자열로 파싱합니다. 따옴표 안 구분자·줄바꿈·이스케이프 따옴표를 지원합니다. 파일 끝의 단일 줄 종료 문자는 데이터 행으로 세지 않으며, 중간의 빈 레코드는 보존합니다.
- 빈/중복 열 이름은 미리보기에서 고유 이름을 제안하고 안내합니다. 열 수가 다른 레코드는 위치와 개수를 알리고 가장 넓은 행까지 모든 값을 보존합니다. 없는 칸만 null로 채웁니다. 잘못된 따옴표·디코딩 실패·Excel 오류 셀은 입력을 차단합니다.
- `번호`, `코드`, `학번`, `ID` 등의 이름 또는 앞자리 0이 있는 값은 식별자로 제안합니다. 의미가 불분명한 정수 열은 범주로 제안합니다. 제안은 확정 전에 수정할 수 있습니다.
- 숫자 변환의 앞자리 0 손실을 안내합니다. NaN, Infinity, 잘못된 숫자, 안전한 정수 범위를 넘는 변환은 거부합니다. 실패를 0이나 결측으로 대체하지 않습니다.
- 날짜는 문자열 저장형과 날짜 의미 유형을 사용합니다. 유효한 `YYYY-MM-DD` 또는 `YYYY-MM-DDTHH:mm:ss[.SSS]`만 허용합니다. XLSX 날짜는 1900/1904 날짜 체계를 고려하고 시간대를 임의로 붙이지 않습니다. 파일에 이미 소실된 앞자리 0·정밀도를 복원하지 않습니다.
- XLSX 수식은 저장된 계산 결과만 읽고 다시 계산하지 않습니다. 캐시 결과가 없으면 안내하고 입력을 차단합니다. 병합 영역의 빈 칸은 자동으로 채우지 않습니다. 선택한 시트의 사용 범위를 처리합니다.
- 원본은 **파싱한 값과 열·셀 메타데이터**입니다. 파일 전체 바이트, 수식 자체, 서식 전체를 재출력하는 기능은 없습니다.
- 수치 통계는 **숫자 저장형이면서 수치 의미 유형인 속성**에만 적용합니다. 숫자로 저장된 식별자·범주는 수치 통계에서 제외합니다. 고유값과 빈도는 결측을 제외합니다.
- 평균·중앙값·최솟값·최댓값은 유효 수치 기준, 표준편차는 **표본 기준 n−1**입니다. n<2일 때 표준편차는 계산 불가입니다. 값이 없는 경우나 계산 범위를 넘는 경우에도 가짜 0을 표시하지 않습니다. 통계 표시 소수점은 최대 6자리입니다.
- 중복은 모든 열의 실제 값과 자료형이 같은 행입니다. null과 빈 문자열은 구분하며, ‘추가 중복’은 각 집단의 첫 행을 뺀 개수입니다. 정렬·필터는 버전을 만들거나 행을 삭제하지 않습니다. 혼합 자료형은 불리언·숫자·문자열 순으로 구분한 뒤 각 자료형 안에서 정렬하며 결측은 항상 마지막입니다.

## 3단계 사용 방법과 저장 정책

상단 **프로젝트 관리**에서 새 프로젝트, 이름 변경, 저장 목록 열기, 삭제, JSON 복원을 사용합니다. 목록에는 수정 시각과 활성 자료 수를 표시합니다. **JSON 백업**은 현재 확정된 상태를 즉시 파일로 내려받습니다. 저장 실패 상태에서도 사용할 수 있습니다. 미확정 입력·편집과 실행 중인 Worker는 백업하지 않습니다.

- 3단계 당시 프로젝트 구조 버전은 **2**(현재는 **4**), 백업 포맷은 **data-garden-project / formatVersion 1**입니다. 포맷 식별자·내보낸 시각·Project·ViewState를 담습니다. 현재 프로젝트와 다른 ID의 사본으로 복원하며, 자료·행·열·버전·작업 ID와 계보는 유지합니다. 프로젝트를 대상으로 한 해석 참조만 새 프로젝트 ID로 바꿉니다.
- 각 자료의 현재 버전은 `activeVersions`에 명시합니다. 되돌린 입력의 자료는 활성 버전이 null인 보관 상태로 남습니다. **되돌리기·다시 실행**은 입력(원본/자료형 적용 두 버전이 한 단위), 셀 편집, 속성 편집, 샘플 열기/닫기를 지원합니다. 정렬·필터·선택·페이지는 화면 상태이며 작업 단위를 만들지 않습니다. 프로젝트 이름 변경은 되돌리기 대상이 아닙니다.
- 기록에는 대상 자료·변경 전후 버전·선택 참조·작업 ID만 넣습니다. 새 분기는 redo 경로를 끊지만 과거 버전·작업·결과는 삭제하지 않습니다. 작업 기록은 한글 변경 내용, 입력/출력 버전 ID, 실행 시각을 20개씩 표시합니다.
- IndexedDB 초기 읽기·검증이 끝나기 전에는 자동 저장하지 않습니다. 실패한 기존 프로젝트를 샘플로 덮어쓰지 않습니다. 변경은 700ms 동안 모아서 저장하고, 저장/삭제 요청을 하나의 직렬 큐에서 처리합니다. 프로젝트 본문·목록·마지막 프로젝트는 동일한 readwrite 트랜잭션으로 저장합니다. 저장 완료 시각은 transaction complete 후에 표시합니다.
- 저장 공간 부족·트랜잭션 실패 시 마지막 정상 저장본과 메모리 자료를 유지합니다. 오류 원인과 재시도·JSON 백업 안내를 제공합니다. 삭제/전체 초기화는 명시적 확인 뒤 실행하며 대기 저장을 무효화합니다. 전체 초기화 뒤에는 빈 공간을 유지하고 새로고침으로 샘플을 다시 저장하지 않습니다. 초기화 여부 표시만 남기며 사용자 설정·프로젝트는 모두 제거합니다.
- 같은 **origin + 배포 경로**에서는 Web Locks로 한 탭만 쓰기 권한을 가집니다. 다른 탭은 읽기 전용이며 JSON 백업을 할 수 있습니다. 쓰기 탭을 닫고 새로고침하면 권한을 다시 얻습니다. Web Locks 미지원 브라우저는 안전하게 읽기 전용으로 동작합니다. 다른 배포 경로와 다른 앱의 저장소는 건드리지 않습니다.
- 원본·모든 버전·작업/undo 기록·분석 설정/결과·그래프·해석·현재 선택·표 화면 설정을 저장합니다. 모든 참조와 필수 필드/자료형, 중복 ID, 유한한 셀 값, 계보, 활성 버전, 기록 순서, 그래프/분석 속성을 검사합니다. 과거 schema 1은 선택 버전을 우선하고 나머지 자료는 마지막 버전을 활성화하며 빈 undo 기록으로 명시적으로 이행합니다. schema 1 이전과 미래 스키마는 거부합니다.
- 원본·자료 버전·분석 조건은 복원 후 다시 동결합니다. 저장 당시 pending/running 분석은 cancelled로 바꾸며 자동 재개하지 않습니다. 과거 결과는 보존하고 `getResultFreshness`로 현재 버전/조건과 비교합니다. 복원 파일 읽기·검증은 JobGate와 전용 Worker를 이용하며 취소·이전 응답은 적용하지 않습니다.
- 프로그램 파일과 사용자 자료의 저장은 분리됩니다. 사용자 자료는 IndexedDB, 앱/파서/Worker/아이콘/샘플을 포함한 정적 빌드 파일은 배포 경로별 Cache Storage에 둡니다. 파일이나 프로젝트를 외부 서버로 전송하지 않습니다.

### 한도와 메모리

CSV/XLSX 한도는 계속 **20MB, 50,000행, 200열, 헤더 포함 500,000셀**입니다. JSON 복원 파일은 **80 MiB**, 원본과 보존 버전 전체를 합한 **300만 셀**까지입니다. 파일 문자열·JSON 객체·독립 복사·동결 과정의 메모리를 감안한 별도 한도이며 행을 잘라서 복원하지 않습니다. 로컬 저장도 300만 보존 셀을 넘기면 마지막 정상 저장본을 유지하고 오류를 안내합니다. 한도를 넘긴 메모리 상태도 JSON 백업은 가능하지만 해당 파일은 이 한도에서 바로 복원할 수 없습니다. 프로젝트를 나누어 작업하세요. 실제 저장 가능 용량은 브라우저/기기 여유 공간에 따라 달라집니다.

필터는 한 속성 조건과 중복 행 조건을 함께 적용할 수 있습니다. 복합 조건 빌더, 원본 파일 바이트의 보존/재출력은 포함하지 않습니다.

### 설치·오프라인·업데이트

HTTPS 또는 localhost에서 사용합니다. 브라우저가 설치 이벤트를 제공하면 프로젝트 관리에 **기기에 앱 설치** 버튼이 나타납니다. manifest의 id/start_url/scope와 아이콘은 상대 경로이며 GitHub Pages 저장소 하위 경로에서도 동작합니다. 설치 버튼을 제공하지 않는 브라우저에서는 브라우저 자체 설치 메뉴를 사용합니다.

첫 연결에서 **오프라인 파일 준비 완료**를 확인한 뒤 재실행할 수 있습니다. 로컬 프로젝트, CSV/XLSX 입력, 편집, 통계 Worker도 캐시 대상입니다. 새 빌드가 내려오면 자동 새로고침하지 않고 적용 안내를 표시합니다. 미확정 작업/계산이 있으면 적용을 보류하고, 최신 상태 저장 성공 후 요청한 탭만 갱신합니다. 저장 실패 시 대기 업데이트를 유지합니다. 다른 탭에서 예전 Worker 파일을 필요로 할 수 있어 여러 탭이 열려 있으면 이전 프로그램 캐시를 보존하고, 단일 탭에서 다음 활성화 때 정리합니다.

## 4단계 사용 방법

1. 자료를 불러온 뒤 **정리** 메뉴를 엽니다. 중앙에는 현재 표와 전후 비교, 오른쪽에는 전처리 설정이 있습니다. 좁은 화면에서는 설정이 아래로 이동하며 ‘정리 설정으로 이동’ 버튼을 사용할 수 있습니다.
2. 처리 종류, 대상 속성과 방법을 고른 다음 **전처리 미리보기**를 누릅니다. 전체 현재 버전의 모든 행을 처리합니다. 표의 필터·정렬·선택 행·현재 페이지는 처리 범위를 바꾸지 않습니다.
3. 행·열 수, 변경 셀과 제거 행, 전체 자료 기준의 속성별 통계·범주 빈도, 실제 계산 기준을 확인합니다. 변경 값·이상값 후보·중복 그룹·행 값 목록은 20개씩 확인합니다.
4. **전처리 적용** 때만 새 버전과 작업 기록이 만들어집니다. 한 번의 적용은 한 번의 되돌리기 단위입니다. 변경 없는 작업과 이상값 표시 전용은 버전을 만들지 않습니다.
5. 취소·실패는 자료를 변경하지 않습니다. 설정·자료 버전 변경은 미리보기와 Worker를 무효화합니다. 저장된 조건은 화면 설정과 독립된 불변 사본입니다. 확정된 결과는 기존 자동 저장·JSON 백업·복원에 포함됩니다.

### 계산 기준과 예외

- **결측:** null과 빈 문자열만. 공백·NA·0·false를 그대로 보존합니다. 선택 속성 중 하나라도/모두 결측인 행 제거, 수치 평균·중앙값, 범주 최빈값, 자료형에 맞는 고정값을 제공합니다. 최빈값 동률은 기준 자료의 행 순서에서 먼저 등장한 값입니다. 전부 결측인 열의 평균·중앙값·최빈값은 실패하며 고정값 등 다른 방법을 안내합니다. 잘못된 숫자·불리언·날짜는 적용하지 않습니다.
- **중복:** 기본은 전체 속성, 선택한 속성의 실제 값과 자료형을 비교합니다. 숫자 1과 문자열 '1', null과 빈 문자열은 구분합니다. 첫/마지막 보존은 현재 자료 버전의 순서이며 화면 정렬과 무관합니다.
- **이상값:** 숫자 저장형·수치 의미 유형만 대상입니다. 정렬된 유효값에서 위치 (n−1)p를 선형 보간하여 Q1/Q3을 구합니다. 기본 경계는 Q1−1.5×IQR, Q3+1.5×IQR이며 배수를 변경할 수 있습니다. 직접 경계 입력도 제공합니다. 경계 미만/초과만 후보이며 경계 자체·결측은 제외합니다. 표시 전용, 하나라도/모두 후보인 행 제거, 후보 셀을 null로 변경, 경계로 제한, 정상 범위 중앙값 대체를 제공합니다. 정상 범위 유효값이 없으면 중앙값 대체를 막습니다. 후보는 오류로 단정하지 않습니다.
- **최소·최대 정규화:** (x−min)/(max−min). **표준화:** (x−mean)/populationSD, 분모 n. 비교 화면 기술통계의 표본 표준편차 n−1과 구분합니다. 결측은 보존합니다. 식별자·범주·날짜 및 분석 제외 속성은 자동 선택하지 않습니다. 유효값 2개 미만, 상수 열, 수치 계산 범위 초과는 실패하며 사용자가 해당 속성을 제외해야 합니다. NaN/Infinity를 저장하지 않습니다. 내부 값은 반올림하지 않고 비교·기준 화면에는 저장 정밀도의 문자열을 표시합니다.
- **검증 허용 오차:** 독립 계산 정답과 수치 결과의 절대 오차 1e-10 이내. 예: [2,4,6]은 minmax=[0,0.5,1], 평균 4, 모집단 표준편차 √(8/3), zscore=[−√1.5,0,√1.5]. 기술통계 표본 표준편차는 2입니다. [1,2,3,4,100]의 Q1=2, Q3=4, IQR 경계=[−1,7], 정상값 중앙값=2.5입니다.

### 저장 구조와 이후 학습·평가 연결

프로젝트 스키마를 **2 → 3**으로 올렸습니다. 스키마 2의 원본·버전·작업 기록은 그대로 유지하고 버전 번호만 이행합니다. 스키마 1은 기존 활성 버전·빈 undo 기록 보완 후 3으로 이행합니다. 과거 기록에 전처리 기준을 임의로 만들어 넣지 않습니다. JSON 백업 봉투 형식은 여전히 formatVersion 1입니다.

- 작업 종류 preprocess와 PreprocessingSettings/FittedPreprocessing/PreprocessingRecord를 추가했습니다. 입력 버전, 최초 전처리 입력, 순서대로 앞선 전처리 작업 ID, 대상 속성 ID, 독립된 설정, 실제 기준, 기준 계산 행 ID·수·전체/학습 범위, 변경 셀 수·제거 행 ID를 보존합니다. 행·열 ID, 원본과 기존 버전은 유지합니다.
- fitPreprocessing은 **주어진 행 범위만** 사용해 기준을 계산하고, applyPreprocessing은 그 기준을 다른 자료에 그대로 적용합니다. 평가 자료로 재계산·보충하지 않습니다. 학습 범위 밖의 값은 minmax 결과가 0~1 밖에 있어도 자동으로 제한하지 않습니다.
- 이후 학습·평가에서는 공통 traceProcessing의 전체 입력 계보와 attributeAncestors의 참조 속성을 찾아 **먼저 분할한 뒤 학습 자료로 다시 fit**해야 합니다. 전체 자료로 전처리된 버전을 단순 분할해 평가하지 않습니다. 실제 모델·분할 UI는 이번 범위에 없습니다.
- 복원 시 방법·자료형·속성/행/버전/계보 참조, 기준 값의 유한성·필수 필드·범위·유효값 수, 변경 개수와 행 순서를 검증합니다. 복원된 원본·버전·계산 기준은 다시 동결합니다.
- 처리 후 사라진 행 선택을 제거하고 페이지를 1로 돌립니다. 기존 getResultFreshness는 현재 참조가 바뀌면 과거 분석을 재분석 필요로 판별하며 당시 기준을 유지합니다.
- 전체 보존 셀(원본+모든 버전) **300만 개** 한도를 적용 전과 reducer에서 검사합니다. 과거 버전을 자동 삭제하지 않습니다. 미리보기 계산 자체는 허용해 변경 내용을 볼 수 있습니다. 프로젝트를 나누어 진행하세요.
- 미리보기·적용·비교 통계는 Worker에서 처리합니다. 현재 표와 설정/기준/계보 ID만 전송하며 프로젝트 전체나 과거 버전 표를 전송하지 않습니다. JobGate와 별도 세대 번호로 취소·조건/버전 변경 후 오래된 응답을 차단합니다. 실제 Worker 종료로 동기 계산도 취소합니다.

## 5단계 사용 방법과 가공 규칙

정리 메뉴의 **정리 작업 영역 → 가공·통합**을 선택합니다. 오른쪽 설정에서 작업·입력·속성·방법을 고르고 **가공 미리보기 → 가공 적용** 순서로 확정합니다. 미리보기와 취소는 자료를 변경하지 않습니다. 좁은 화면에서는 **정리 설정으로 이동**으로 아래쪽 설정을 엽니다. 기존 전처리는 같은 영역 선택에서 계속 사용할 수 있습니다.

- **범위·버전:** 선택한 자료의 현재 버전 전체 행을 사용합니다. 표 필터·정렬·선택·페이지는 가공 범위를 바꾸지 않습니다. 계산·날짜·인코딩·구간화는 기존 행·열 ID를 유지한 새 버전, 결합·이어 붙이기·집계는 새 자료·행·열·버전 ID를 가진 파생 자료입니다. 파생 자료의 최초 결과는 입력 파일 원본과 구분해 표시합니다.
- **계산 열:** 속성/상수 선택과 더하기·빼기·곱하기·나누기·합계·평균·비율·백분율을 제공합니다. 비율은 첫 값/둘째 값, 백분율은 그 값×100입니다. 숫자 저장형·수치 의미 유형만 피연산자로 선택합니다. 기본 결측 전파, 합계/평균의 명시적 결측 제외, 행별 유효 피연산자 수를 제공합니다. 유효값 0개는 null입니다. 0 나누기·잘못된 수치·범위 초과는 적용 차단 또는 명시적 결과 결측 정책이며 원래 값은 유지합니다. 문자열 수식 실행/eval/Function은 사용하지 않습니다. 내부 결과는 반올림하지 않습니다.
- **날짜 분리:** 기존 유효 날짜 문자열에서 연도·월·일·분기·요일·시·분·초를 분리합니다. 기기 시간대 변환 없이 날짜 구성 요소를 사용하며 요일은 월요일=1~일요일=7입니다. 날짜에 시각이 없으면 시·분·초는 null과 안내를 남깁니다. 월·분기·요일은 기본 범주이며 생성 열의 이름·설명·숫자/문자열 저장형·의미를 설정할 수 있습니다.
- **범주 인코딩:** 범주 숫자 코드는 기본 등장 순서의 0부터 시작하며 범주 의미를 유지합니다. 대응표에서 명시적 코드 순서를 지정할 수 있습니다. 원핫은 원래 열을 보존하고, 기준 범주 제외 여부와 실제 기준 범주를 저장합니다. 결측/명시적으로 허용한 미등록 범주는 모든 결과 열 null이며, 제외된 기준 범주의 모두 0과 구분합니다. 새 범주로 출력 열을 자동 확장하지 않습니다. 공백·대소문자·숫자 1/문자열 '1'을 구분합니다.
- **구간화:** 동일 폭 또는 (n−1)p 선형 보간 분위수를 사용합니다. 구간은 왼쪽 포함·오른쪽 제외이며 마지막만 양끝 포함입니다. 중복 경계는 통합하고 요청/실제 구간 수와 빈도를 표시합니다. 같은 값은 같은 구간에 들어갑니다. 상수 열은 차단합니다. 범주 이름은 경계를 바꾸지 않습니다. 기준 범위 밖의 값은 미리 선택한 결측/차단/끝 구간 정책을 사용하며 경계를 다시 넓히지 않습니다.
- **결합:** 서로 다른 두 입력 버전의 단일/복합 키, 내부·왼쪽·전체 외부 결합을 제공합니다. 실제 자료형과 값으로 비교하고 null·빈 문자열 키는 연결하지 않습니다. 중복 키는 실제 조합을 만들며 다대다는 예상 행 수를 확인해야 적용할 수 있습니다. 양쪽 키 열을 모두 보존하고 중복 이름에는 출처/번호를 붙입니다. 출력 이름을 직접 바꿀 수 있습니다. 결측 키를 제외한 키별 관계와 입력 행 ID를 표시하며, 결측 키 행도 미연결 행 수와 결과 출처에 포함합니다.
- **이어 붙이기:** 2개 이상 자료의 입력 순서를 고르고 이름 기반 열 대응 제안을 수정·확인합니다. 각 열은 기존 대응/새 별도 열/명시적 제외 중 선택합니다. 없는 칸은 null, 같은 행도 그대로 유지합니다. 유형 충돌은 차단하거나 명시적으로 혼합 저장형·텍스트 의미를 선택하여 변환 없이 보존합니다. 입력 순서 또는 대응 변경 후에는 다시 확인해야 합니다.
- **그룹 집계:** 복수 그룹 속성, 행 수·유효값 수·합계·평균·최소·최대·중앙값을 지원합니다. 수치 집계는 수치 의미만 대상이고 전부 결측인 합계·평균 등은 null입니다. 결측 그룹 포함 시 null과 빈 문자열을 각각 유지합니다. 각 결과 그룹의 구성 행 ID를 페이지 목록으로 확인할 수 있습니다.
- **표시:** 결과 표 25행, 문제/사전/구간/키/출처 목록 20개씩 페이지 분할합니다. 열 이름 충돌은 (2), (3) 등으로 구분하고 미리보기의 실제 열 이름·저장형·의미·참조 속성에서 확인합니다. 입력 버전 또는 설정 변경 시 기존 미리보기를 무효화합니다. 확정된 파생 자료는 당시 입력 버전을 계속 사용하고 입력 갱신/비활성 상태를 전체 가공 이력에 표시합니다.

### 5단계 저장 구조와 공통 연결

프로젝트 **schemaVersion 4**, 백업 봉투 **formatVersion 1**입니다. schema 1은 활성 버전·빈 되돌리기 기록을 보완하고, schema 2/3은 구조 번호만 4로 이행합니다. 과거 전처리 기록이나 기준은 재작성하지 않습니다.

- 새 작업 종류 wrangle과 WranglingSettings/FittedWrangling/WranglingRecord를 추가했습니다. 모든 입력을 자료 ID+버전 ID로 기록하고 출력 자료·버전, 새 열별 입력 속성, 행별 입력 행 목록을 보존합니다. 기존 parentVersionIds는 같은 자료 안의 부모만 유지하며 다중 자료 연결은 명시적 입력 참조로 검사합니다.
- fitWrangling과 applyWrangling을 분리했습니다. 인코딩 사전·코드·출력 열 ID, 구간 경계, 입력 속성의 저장형/의미, 기준 계산 전체/학습 행 ID·개수를 고정합니다. 적용 함수는 재학습하지 않습니다. 이후 평가 자료에는 같은 속성 ID와 호환되는 저장형·의미가 필요합니다. 실제 학습/평가 UI는 제공하지 않습니다.
- traceProcessing은 전처리·계산·날짜·인코딩·구간·편집과 다중 입력을 모두 포함하는 위상 순서 이력입니다. attributeAncestors는 계산/집계/그룹/결합 키 의존성을 원래 속성까지 추적합니다. 그룹 통계를 개별 행에 다시 결합한 경우도 집계 입력 버전과 전체/학습 행 범위를 확인할 수 있습니다. 기존 preprocessingLineage는 과거 전처리 기록의 검증 호환용으로 유지합니다.
- 복원은 모든 자료·버전·행·속성 참조와 순환, 방법별 설정·계산 기준, 보존 입력으로 재구성한 결과와 출처, 최초 파생 결과, 활성 버전과 되돌리기 순서를 검증합니다. 출력 UUID를 대응하여 검사하며 저장된 ID/기준을 재작성하지 않습니다. 비활성 입력도 보존본이 있으면 유효합니다. 향후 계산 규칙을 바꿀 때는 기록 formatVersion과 이행 규칙을 함께 확장해야 합니다.
- 한 번 적용을 한 작업 단위로 기록하고 기존 undo/redo·분기·자동 저장·백업·사본 복원과 연결했습니다. 되돌린 파생 자료는 비활성으로 남고 새 분기에서 과거 보존본을 지우지 않습니다. Worker 전송 후 잃는 동결 상태는 프로젝트 교체 경계에서 다시 복구합니다.
- 가공 크기 추정·계산·JSON 복원·브라우저 IndexedDB 로드 검증은 Worker에서 수행합니다. 가공 요청에는 선택한 입력 표와 설정/기준만 전달하며 프로젝트 전체·과거 표를 보내지 않습니다. 전체 프로젝트 전달은 복원 검증 작업에만 사용합니다. JobGate의 jobId/scopeId, 세대 번호, 실제 Worker 종료, 최종 reducer의 활성 입력 참조 검사를 함께 사용합니다.
- 결과는 **50,000행·200열·머리글 포함 500,000셀** 이하입니다. 다대다 행 수는 결과 행을 할당하기 전에 추정합니다. **원본+모든 보존 버전 300만 셀**에 새 파생 자료의 최초 보존본과 첫 버전 두 복사본을 포함합니다. 미리보기·적용·최종 등록에서 검사하며 초과 시 부분 등록/자동 잘라내기/과거 버전 삭제 없이 거부합니다. JSON 파일 한도 80 MiB와 브라우저 실제 저장 공간 한도도 유지합니다.

## 6단계 — 실제 시각화

현재 앱은 **v0.6.0 / 프로젝트 schemaVersion 5 / 백업 formatVersion 1**입니다. 앞의 1~5단계 설명과 검증은 당시 기록이며, 해당 단계에 기재한 스키마 번호는 현재 번호와 다릅니다.

### 사용 방법

1. 자료를 선택하고 **시각화 → 그래프 만들기**를 누릅니다.
2. 오른쪽에서 종류·자료 범위·속성·집계·집단을 고릅니다. 설정은 300ms 동안 모아 계산하며, 변경 즉시 이전 결과를 숨기고 이전 작업을 무효화합니다.
3. 그래프 또는 집계표의 **자료 보기**를 누르면 당시 버전의 입력 행을 25행씩 조회합니다. 산점도는 숫자 범위를 입력하는 영역 선택도 제공합니다. 겹친 점의 모든 행을 확인할 수 있습니다.
4. **그래프 저장**으로 확정합니다. 이름은 설정의 그래프 이름을 수정한 뒤 저장합니다. 복제·삭제·저장 목록·두 그래프 비교를 지원하며, 비교는 좁은 화면에서 위아래로 배치합니다.
5. 집단의 나누어 보기는 같은 계산 결과의 공통 축·구간·집계 기준을 사용합니다. 한 번에 최대 4개 패널을 보여주며 페이지를 이동합니다.

저장된 그래프는 정확한 자료 ID·버전 ID를 계속 참조합니다. 자료 편집 후 **자료 버전 변경**을 표시하고, 현재 버전으로 복제하여 다시 그릴 수 있습니다. 이때 범위를 전체로 초기화하고 예전 그래프를 보존합니다. 그래프 저장·삭제·선택은 자료 버전이나 데이터 undo/redo 기록을 추가하지 않습니다. 현재 그래프·비교 그래프 선택도 자동 저장·JSON 백업에 포함됩니다.

### 계산·표시 기준

- **범위:** 전체, 저장한 표 필터(페이지와 무관한 모든 일치 행, 중복만 조건 포함), 저장한 선택 행 ID. 빈 선택은 0행입니다. 조건을 독립 복사하므로 이후 표를 바꿔도 변하지 않습니다. ‘현재 표 조건 다시 가져오기’로 명시적으로 갱신합니다.
- **수치:** 숫자 저장형이면서 수치 의미인 속성만 연속 축·수치 집계·상관에 사용합니다. 숫자 식별자·범주는 자동으로 수치로 해석하지 않습니다. null·빈 문자열만 결측이고 0·NA는 그대로입니다. 범주 키는 실제 자료형을 구분하고, 화면에서 숫자/불리언은 유형을 붙이며 문자열은 따옴표로 구분합니다.
- **산점도:** 실제 X/Y와 집단별 기호·색상. 중복 좌표의 행 수를 전체 범위에서 계산합니다. 점 또는 양끝 포함 영역의 입력 행을 Worker에서 조회합니다. 영역 조회는 표시 표본에 한정하지 않습니다.
- **히스토그램:** 동일 폭 구간 수(1~100) 또는 폭. 모든 집단에 동일한 실제 경계를 적용합니다. [왼쪽, 오른쪽), 마지막만 최댓값 포함. 상수는 하나의 구간. 부동소수점 정밀도에서 중복되는 경계는 통합하여 안내합니다. 비율 분모는 각 집단의 유효 수치 행 수입니다. 실제 경계를 저장하고 복원 시 방법·범위와의 일치를 검증합니다.
- **상자그림:** (n−1)p 선형 보간 Q1/중앙값/Q3/IQR. 수염은 1.5×IQR 울타리 안의 실제 최솟값·최댓값. 울타리 밖 값은 별도 점으로 표시하며 삭제하지 않습니다. 동일한 이상값도 모든 입력 행을 조회합니다.
- **막대:** 범주별 행 수, 유효 수치 수, 합계, 평균, 중앙값. 집단별 나란히/누적과 범주 순서 선택. 양·음수 누적 범위를 각각 계산합니다. 전부 결측인 합계·평균·중앙값은 null이며 행 수/유효 수만 0이 가능합니다.
- **선:** 날짜·수치 X를 오름차순으로 배치하고 동일한 실제 X값을 선택한 방법으로 집계합니다. 범주형 X는 연결 순서를 확인해야 합니다. 없는 조합은 공백이며 자동 연결하지 않습니다. 날짜에는 시간대 변환 없이 입력 달력 값을 사용하는 UTC 축을 적용합니다.
- **파이:** 비음수 집계값, 표시 범주 합계에 대한 비율·분모. 음수·총합 0·overflow는 오류로 안내합니다. 절댓값 변환이나 임의 삭제를 하지 않습니다.
- **누적 영역:** 날짜/수치 X와 집단을 요구하며 음수 집계는 차단합니다. 없는 조합과 실제 행의 결측을 구분합니다. 명시적으로 선택한 경우에만 없는 조합을 0으로 표시하며 실제 전부 결측 집계는 공백으로 남깁니다. Worker가 시점별 합계를 계산하며 집단 공백이 있으면 전체 합계는 계산 불가입니다.
- **교차 히트맵:** X/Y 범주 조합의 행 수 또는 수치 집계. 없는 조합의 빈도 0과 계산할 수치가 없는 null을 구분합니다. 색상 범례와 값 표, 셀별 입력 행 조회를 제공합니다.
- **상관 히트맵:** Pearson, 속성 쌍별 유효 행으로 계산하고 n을 표시합니다. 상수 또는 n<2는 null로 남기고 빈 칸·계산 불가로 안내합니다. 색 범위는 −1~1이며 인과관계 설명을 생성하지 않습니다.
- 집계표는 25개씩 표시하며 화면 숫자는 최대 유효숫자 8자리로 반올림합니다. 계산은 표본 추정이 아닌 전체 대상 자료의 값을 사용합니다. 구간 경계와 상세 근거는 실제 계산값을 제공합니다. 직접 지정한 축 범위 밖 자료는 그래프에서 잘릴 수 있으나 집계표와 입력 행에는 보존됩니다.

### 계산·표시 한도

- 그래프 계산 **50,000행**, 집단 **20개**, 표시 X범주 **100개**, 교차 Y범주 **100개**, 범주×집단/교차 칸 **2,000개**, 상관 속성 **20개** 이하입니다.
- 범주 기본 표시 한도는 30개입니다. 이를 넘으면 표시 시작·개수와 제외 정책을 사용자가 확인해야 계산합니다. 제외한 범주 수를 알리고 ‘기타’로 합치지 않습니다. 파이 분모도 표시 범주 집계 합계임을 명시합니다.
- Canvas로 렌더링합니다. 산점도·이상값 표시점은 기본 3,000개, 설정 최대 5,000개입니다. 초과 시 reservoir 표본을 사용하며 전체/표본 수·방법·seed를 표시합니다. 32비트 LCG(1664525×state+1013904223) 기반으로 seed와 원래 행 순서가 같으면 같은 표본입니다. 집계·요약·영역 조회는 여전히 전체 범위 기준이며 근사 통계를 사용하지 않습니다.
- 이 PC의 프로덕션 브라우저에서 **49,999행·2열 / 3,000점 표시**의 Worker 계산은 약 **127~150ms**, 같은 자료의 2구간 히스토그램은 약 **91ms**였습니다. 이는 Worker 내부 계산 시간으로 초기 파일 로딩·메시지 복사·렌더링 전체 시간이 아닙니다. 학교 PC의 메모리와 처리 속도를 보장하는 수치는 아닙니다.
- 모든 집계 칸에 행 목록을 복사하지 않습니다. 결과에는 속성·값·구간 등의 작은 조회 조건만 담고, 클릭 시 해당 버전의 표를 Worker에서 검색하여 25행씩 반환합니다.
- 계산·목록 조회는 기존 DataTask/WorkerRunner/JobGate를 사용합니다. 선택한 표와 설정만 전송하며 프로젝트 전체·과거 표를 전달하지 않습니다. 요청 대기 및 실행 중 취소, Worker 종료, jobId/scopeId 검사, 결과의 설정 키 검사로 이전 결과의 덮어쓰기를 막습니다.

### 저장·복원과 의존성

GraphConfig에 선택적인 visual(formatVersion 1) 설정을 추가했습니다. 기존 axes/grouping/bins/aggregation은 확정 시 같은 설정으로 정규화합니다. 저장 항목은 이름·시각, 정확한 자료 참조, 속성 ID, 범위 사본, 집계·구간·실제 경계, 순서·표시 정책, 축·단위, 표본 조건입니다. 차트 객체·DOM·Worker·함수·집계 결과 표·원자료 복사본은 저장하지 않습니다.

스키마 1~4를 5로 이행하며 과거 작업과 그래프를 재작성하지 않습니다. 과거 그래프에 필수 visual 설정이 없으면 ‘설정 보완’을 안내하고 계산하지 않습니다. 복원 시 그래프 종류·버전·속성·선택 행·필터·필수 의미 유형·유한한 범위·집계 방법·표본 설정·히스토그램 경계를 검증합니다. 읽기 전용 탭은 기존 쓰기 잠금과 비활성화된 조작 화면으로 저장·삭제를 막습니다.

**Apache ECharts 6.1.0**과 zrender 6.1.0을 npm 의존성으로 추가했습니다. 공식 [지원 차트](https://echarts.apache.org/en/feature.html), [모듈별 가져오기](https://echarts.apache.org/handbook/en/basics/import/), [Canvas 성능 기준](https://echarts.apache.org/handbook/en/best-practices/canvas-vs-svg/), [접근성·무늬](https://echarts.apache.org/handbook/en/best-practices/aria/), [Apache-2.0 라이선스](https://github.com/apache/echarts/blob/master/LICENSE)를 확인해 선정했습니다. 필요한 차트와 Canvas 렌더러만 등록하고 별도 청크로 지연 로드합니다. 대체 설명과 키보드로 사용할 수 있는 값 표를 함께 제공합니다. 필수 정보를 hover에만 두지 않으며 툴팁 HTML을 사용하지 않습니다. 이름·범주는 React/Canvas의 일반 텍스트로 표시합니다.

## 7단계 — 회귀 분석

### 사용법

1. 자료를 선택하고 **분석** 메뉴를 엽니다. 오른쪽에서 수치 의미의 **예측 대상 1개·입력 속성·복수 모델**을 직접 선택합니다. 분석 제외 열은 데이터 메뉴의 속성 편집에서 변경합니다. 숫자 ID·범주는 연속형 입력으로 자동 사용하지 않습니다. 범주는 기존 정리 메뉴에서 **원핫 인코딩**으로 준비합니다.
2. 전체·필터 전체·선택 행 범위, 기본 **70:30 / seed 2026**, 결측 제거·학습 평균·중앙값, 정규화 없음·minmax·zscore, k를 정합니다. 트리 깊이·최소 리프 행 수·이웃 가중치는 고급 설정에 있습니다. 실행 전 버전·행 수·관측 수·입력·처리 순서를 확인합니다.
3. **회귀 실행 · 새 기록**은 공통 분할과 전처리를 한 번 만들고 선택한 모델을 Worker에서 계산합니다. 메뉴 이동은 가능하며 조건·자료 변경과 취소는 Worker를 종료합니다. 진행률 대신 실제 계산 단계를 표시합니다.
4. 중앙에서 MAE·MSE·RMSE·R², 모델 실패 원인, 25행씩 나눈 평가 표, 오차 그래프를 봅니다. **근거 보기**에서 당시 버전의 원자료, 계수별 기여, 트리 경로, 실제 학습 이웃·거리·가중치를 확인합니다. 현재 활성 자료 버전은 바꾸지 않습니다.
5. **새 입력값 예측**은 원래 수치·범주·날짜를 받아 고정된 학습 기준·모델만 적용합니다. 정답 없는 새 관측이며 평가 점수에 포함하지 않습니다. 학습 범위 밖은 외삽 경고를 표시합니다. CSV 입력 시 이미 확인한 변환과 원본은 보존합니다.
6. **결과** 메뉴에서 기록 선택·두 실행 비교·당시 조건 재실행·현재 버전으로 조건 복제·삭제를 합니다. 조건을 바꾸면 과거 결과는 유지하고 **재분석 필요**를 표시합니다. 같은 자료의 과거 분할을 명시적으로 재사용할 수 있으며, 이때 저장된 행 배치가 비율·seed보다 우선합니다.

### 분할·전처리와 지원 경로

- 계산 규칙은 regression-1, 설정·결과 formatVersion은 1입니다. 대상 관측 ID를 정렬한 뒤 32비트 LCG/Fisher–Yates로 섞습니다. 신규 분할의 학습 관측 수는 floor(관측 수 × 학습 비율), 나머지는 평가입니다. 실제 행 ID를 보존하며 정렬·표 페이지와 무관합니다. 학습 2행·평가 1행 미만이면 자동 보정 없이 차단합니다.
- 정답의 원래 관측이 null·빈 문자열이거나 유한한 수치가 아니면 분할 전에 제외합니다. 이전에 정답을 평균 등으로 대체했어도 대체값을 정답으로 평가하지 않습니다. 입력 결측과 가공 중 제거는 학습·평가별로 따로 기록하고 모든 모델에 같은 유효 평가 행을 씁니다.
- 현재 버전 범위 안의 관측을 대상으로 traceProcessing/attributeAncestors와 실제 속성 의존 경로를 검사합니다. 과거 정리에서 이미 제외되어 **현재 버전에 없는 행은 범위에 다시 넣지 않습니다**. 그 행까지 평가하려면 제거 전 버전을 사용하세요. 필터 조건과 실제 범위 행 ID도 각각 저장합니다.
- **지원:** 단일 자료의 결측·이상값·스케일링, 행별 계산, 날짜 분리, 원핫, 구간화 및 후속 인코딩, 셀·속성 편집 이력. 가공 순서를 유지하고 필요한 입력만 역추적합니다. 행 제거의 any/all 조건에 필요한 미선택 열도 유지합니다. CSV/XLSX의 최초 자료형·표시값 확정은 통계적 학습이 아닌 행별 변환이므로 해당 보존 버전에서 시작합니다.
- **학습에서만 fit:** 평균·중앙값·최빈값·IQR·최솟값·최댓값·평균·모집단 표준편차(n), 범주 사전·구간 경계. 평가/새 입력에는 apply만 합니다. 원핫 출력 ID는 기존 선택과 연결하고 사전 밖 값은 기존 가공의 block/missing 정책을 지킵니다. 학습에서 사라진 선택 원핫 열은 상수일 수 있어 선형회귀가 이유를 표시합니다. 고정 기준 범주가 학습에 없으면 기준을 임의 변경하지 않습니다.
- **정답 경로 제한:** 정답 자체·정답을 사용해 계산한 입력을 차단합니다. 단순히 공통 원천이 있다는 이유만으로 별개의 파생 입력을 금지하지 않습니다. 원래 단위·의미를 복원하지 못하는 파생 정답과 정답에 대한 스케일링·이상값 처리 등은 실행 전에 차단합니다. 원래 관측 정답을 선택하세요. 범주 코드의 의미를 수치로 바꾸어 원핫 대신 사용하는 우회도 차단합니다.
- **다중 자료:** 통계 가공이 없는 결합·누적의 보존 표를 사용할 수 있습니다. 결합 대상 열의 실제 값 출처와 rowSources로 복제 관측을 묶으며, 공통 참조표의 행만 같다고 모두 묶지 않습니다. 같은 관측 복제본은 한쪽 분할에만 들어갑니다. 안전한 단위를 판별하지 못하거나 집계·통계·인코딩·구간화가 포함된 다중 입력 경로(그룹 평균 재결합 포함)는 구체적인 이유와 함께 차단합니다. 이 경로의 새 입력 예측은 입력별 키/행 대응이 없어 지원하지 않습니다. 단일 자료 또는 통계 가공 전 자료로 준비하세요.
- 결과에는 원자료 표 전체를 복사하지 않습니다. 필요한 버전 참조·범위·분할·고정 기준·특성 대응·직렬화 모델·평가값만 보존하며 kNN은 학습 행 ID와 고정 기준으로 행렬을 복구합니다. 복원·결과 조회에서 모델을 다시 학습하지 않습니다.

### 모델과 평가 규칙

- **선형회귀:** 절편 포함 단순/다중 회귀. 수치 균형 조정 후 Householder QR로 최소제곱을 구하고 계수를 모델 입력 단위로 돌려놓습니다. 정규방정식 역행렬·ridge·임의 계수 조정을 사용하지 않습니다. 학습 행은 입력 수+2 이상, 상수·선형 종속과 정규화된 QR 열 norm ≤ 1e-10√n이면 실패 이유를 표시합니다. 화면의 계수는 전처리가 적용된 실제 모델 특성 기준입니다.
- **회귀 트리:** 모든 입력의 인접한 서로 다른 값 사이 경계를 탐색하여 제곱 오차 감소가 최대인 분할을 선택합니다. 리프는 학습 정답 평균, 기본 깊이 4·최소 리프 2행입니다. 정규화된 감소량의 1e-12 동률은 입력 순서·낮은 경계 순입니다. 깊이·최소 리프·상수 정답·개선 없음에서 멈추며 노드 수·실제 탐색량을 저장합니다.
- **kNN:** 유클리드 거리, 기본 k=3과 동일 가중 평균. 동일 거리는 행 ID 순입니다. 거리 역수 가중 선택 시 최소 거리로 상대 가중치를 안정적으로 계산합니다. 선택한 k개 안에 거리 0이 있으면 그 이웃만 동일 가중치로 사용합니다. k가 유효 학습 행보다 크면 줄이지 않고 해당 모델을 실패 처리합니다. 평가 행은 후보에 들어가지 않습니다.
- **잔차 = 실제 − 예측**. MAE=Σ|잔차|/n, MSE=Σ잔차²/n, RMSE=√MSE, R²=1−Σ잔차²/Σ(실제−실제 평균)². 실제 분자·분모·n도 표시합니다. R² 음수는 그대로, n<2·정답 분산 0은 null+이유입니다. 표현 불가능한 계산은 오류로 차단하며 NaN/Infinity/가짜 0을 저장하지 않습니다.
- 점수는 전체 유효 평가 행 기준입니다. 그래프는 기존 ECharts 등록을 재사용한 실제/예측 및 예측/잔차 산점도와 항등선·잔차0 기준선입니다. 표시만 최대 1,000행 reservoir 표본(seed 저장)을 쓰며 표·점수는 표본으로 줄이지 않습니다. 점 선택은 해당 평가 페이지와 당시 자료에 연결됩니다. 모든 화면 수치는 유효숫자 7자리로 표시합니다.
- 모델 하나의 실패와 공통 파이프라인 실패를 구분합니다. 실패 모델의 점수를 0으로 만들지 않습니다. 두 실행의 직접 비교 조건은 평가 행 ID·정답·관측 단위·목표 단위의 일치 여부로 판단합니다. 인과·정책 효과 해석이나 자동 최적 모델 선정은 제공하지 않습니다.

새 계산 의존성은 추가하지 않았습니다. 수치 방식 선정에 [LAPACK 최소제곱 QR 문서](https://www.netlib.org/lapack/lug/node27.html), [회귀 트리 공식 설명](https://scikit-learn.org/stable/modules/tree.html), [최근접 이웃 공식 설명](https://scikit-learn.org/stable/modules/neighbors.html)을 확인했으며 TypeScript 계산을 로컬 Worker에 구현했습니다. scikit-learn/LAPACK을 브라우저에서 호출하거나 다운로드하지 않습니다. 기존 ECharts 라이선스·번들·캐시 방식을 유지합니다.

### 사용법

1. **분석 → 분석 영역 → 군집**에서 현재 자료의 수치 속성 1개 이상을 선택합니다. ID·범주·분석 제외 열은 선택하지 않습니다. 원핫 열을 선택하면 각각 거리의 한 차원입니다.
2. 전체·현재 필터 전체·선택 행 중 범위를 정합니다. 페이지·정렬에 무관하며 빈 선택은 0행입니다. 범위는 당시 조건을 복사하므로 표에서 필터를 바꾼 뒤에는 **현재 표의 범위 다시 가져오기**를 누릅니다.
3. k 목록(예: `2, 3, 4`), 결측 처리, 추가 정규화와 seed를 정합니다. 고급 설정에서 초기화·재시작·최대 반복·이동 허용값·실루엣 평가를 정하고 실행합니다. 목표값이나 학습/평가 분할은 없습니다.
4. 선택 버전의 **현재 값**을 사용합니다. 과거 전처리를 재실행하지 않습니다. 가공 이력과 이번 추가 대체·스케일 기준, 실제 행 ID, 제외/대체 행은 결과의 당시 조건에서 확인합니다.
5. k별 SSE·실루엣·크기·수렴·소요 시간, 재시작 결과, 실제 반복 단계, 행별 거리·SSE 기여를 확인합니다. 축은 화면 상태이며 라벨과 최신 여부에 영향을 주지 않습니다. 1차원은 Y축 없음, 다차원은 두 축만 표시합니다.
6. 군집 또는 좌표 영역을 선택하면 **전체 입력**에서 해당 행을 찾고 25행씩 표시합니다. 겹친 점도 좌표 범위 조회에 모두 포함됩니다. 행을 선택하면 당시 관측값과 분석 공간 좌표, 할당/표시 중심별 거리, a·b의 거리 합·나눗수·개별 실루엣을 Worker에서 계산합니다.
7. 관측값과 추가 대체·스케일 후 분석값 통계를 구분합니다. 수치 평균·중앙값·범위·표본 표준편차(n−1), 공통 경계 10구간 분포(상수 1구간), 범주 빈도와 비율을 제공합니다. 관측 통계는 선택한 군집/영역의 모든 행과 전체 입력을 비교합니다. 비계산 표시 축의 평균은 K-means 중심이라고 표시하지 않습니다.
8. 두 저장 실행의 실제 입력 행·버전·속성 순서·전처리 공간 차이를 표시합니다. 같은 자료의 같은 행 집합이면 군집 번호에 관계없이 **교차 겹침 표**를 제공합니다. 군집 번호 변화율이나 자동 최적 k를 만들지 않습니다.

### 계산 규칙 `kmeans-1`

- 유클리드 거리. SSE = 각 입력점에서 **최종 최근접 중심까지의 제곱 거리 합**. 중복 좌표도 별도 행으로 유지해 빈도만큼 기여합니다. 내부 반올림 없이 유한성을 검사합니다.
- 기본 초기화 k-means++: 첫 점은 균등 무작위, 이후 최근접 중심 제곱 거리에 비례하여 뽑습니다. 무작위 초기화는 아직 선택하지 않은 서로 다른 벡터를 가진 행에서 선택합니다. 직접 중심도 가능합니다. k는 행 수와 서로 다른 벡터 수 이하이어야 합니다.
- 행 ID 사전 순서로 계산해 화면 정렬과 독립입니다. PRNG는 32비트 LCG(1664525, 1013904223), 재시작 seed는 `(seed + i × 2654435761) mod 2³²`입니다. 계산에 시각·Math.random을 사용하지 않습니다. 모든 k에서 같은 입력·전처리·재시작 seed 규칙을 사용합니다.
- 최근접 동률은 작은 군집 번호. 빈 군집은 구성원이 2개 이상인 군집의 점 중 기존 중심과 다른 가장 먼 점으로 재초기화합니다. 동률은 행 ID 순서, 이벤트를 저장합니다. k회 안에 해소하지 못하면 그 재시작은 실패로 남깁니다.
- 매회 **할당에 사용한 중심**과 **그 구성원의 평균으로 갱신한 중심**을 별도 저장합니다. 전체 차원의 중심 이동량은 Frobenius norm입니다. 갱신 후 최근접 라벨이 같을 때만 평균·할당 고정점 수렴입니다. 이동 허용값 이하라도 라벨이 바뀌면 미수렴 종료, 최대 반복 종료도 미수렴입니다.
- 종료 후 최종 중심에 최근접 재할당하고 변경 여부를 기록합니다. 이 상태의 라벨·거리·SSE는 일치합니다. 미수렴 결과의 중심은 최종 라벨 평균과 다를 수 있음을 명시합니다. 최종 빈 군집은 실패 처리합니다.
- 완료 재시작 중 최소 SSE를 채택하며 동률은 먼저 실행한 회차입니다. 모든 초기 중심과 반복별 중심·구성원 수·SSE·이동·이벤트를 저장하고, 전체 행×k×반복 거리 배열은 저장하지 않습니다. 과정 조회는 고정 이력을 읽어 해당 단계의 할당을 계산하며 다시 군집화하지 않습니다.
- 결측은 `null`·빈 문자열만 해당합니다. 제거 또는 선택 범위 유효값의 평균/중앙값 대체 후 스케일을 구합니다. min-max는 (x−최소)/(최대−최소), Z점수는 (x−평균)/모집단 표준편차(n). 전부 결측, 변환 불가능한 상수, 비수치, NaN·Infinity·거리 범위 초과를 가짜 0으로 바꾸지 않습니다.

### 실루엣

공식 정의는 [scikit-learn silhouette_samples](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.silhouette_samples.html) 및 [공식 구현의 단독 구성원 처리](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/metrics/cluster/_unsupervised.py)를 확인했습니다. 외부 코드를 실행하거나 의존성을 추가하지 않았습니다.

`a`: 자신을 제외한 같은 군집 구성원까지의 평균 유클리드 거리. `b`: 다른 군집 각각의 구성원까지 평균 거리 중 최솟값. `(b−a)/max(a,b)`를 사용하며 중심까지의 거리·제곱 거리로 대체하지 않습니다. 2 ≤ 실제 k ≤ N−1에서만 정의합니다. 단독 구성원과 a=b=0은 개별 값 0, k=1·k=N·평가 끔은 `null`과 이유를 저장합니다.

**정확 계산**은 모든 점을 평가합니다. **표본 추정**은 고정 seed로 전체 행에서 비복원 균등 평가점을 추출하고, 각 평가점의 a·b는 해당 군집의 **전체 실제 구성원**으로 계산합니다. 표본을 다시 군집화하거나 표본 안에서 단독 군집이라고 판단하지 않습니다. 표본 크기 ≥ N이면 정확 계산으로 표시합니다. 모든 k에서 동일한 평가 행 ID를 공유합니다. 전체 추정 평균은 평가점의 단순 평균이며 군집별 평균의 단순 평균이 아닙니다. 군집별 실제 크기·평가 수를 저장하고 평가점이 없는 군집은 null과 이유를 표시합니다. N×N 거리 행렬은 만들지 않습니다. 선택 행의 실루엣은 표본 선정 여부와 무관하게 전체 구성원 기준으로 조회할 수 있습니다.

**입력 전체 / 최대 1,000개 표시점 / 실루엣 평가 표본은 서로 다릅니다.** 표시 표본(seed 2718)은 계산·통계·영역 조회에 영향을 주지 않습니다. 실제 군집 학습을 몰래 표본으로 바꾸지 않습니다.

### 직접 점 실험과 저장

**분석 영역 → 직접 점 실험**에서 점 추가·좌표 수정(이동)·삭제를 합니다. 산점도/표에서 점을 선택하고 좌표 입력란을 키보드로 수정할 수 있습니다. 포인터 드래그나 자동 재생은 제공하지 않으며, 처음·이전·다음·최종 단계 버튼으로 탐색합니다.

임시 좌표는 앱의 미확정 작업 보호에 연결됩니다. **좌표를 새 자료로 확정 저장**하면 `SourceInfo.kind=manual`인 원본·첫 버전·입력 작업·되돌리기 기록을 가진 새 자료가 됩니다. 수정한 실험을 저장해도 이전 자료와 결과는 남습니다. 각 버전 안의 행 ID는 보존하며 전역 데이터셋/버전 ID는 새로 발급합니다. 저장 결과는 반드시 확정한 자료 버전을 참조합니다. 저장 후 일반 군집과 동일한 엔진·설정으로 실행합니다. 미확정 편집 중 과거 결과는 수정 전 확정 자료의 결과임을 표시합니다. 현재 실험 비우기는 전체 프로젝트 초기화와 별개입니다.

직접 중심은 계산 속성 순서로 한 줄당 한 중심, 쉼표로 좌표를 입력합니다. **선택 버전 단위**를 사용하고 점과 같은 고정 스케일 기준으로 변환합니다. 서로 다른 k개 중심, 정확한 차원, 유한 좌표를 검사하며 직접 초기화는 단일 k·재시작 1회입니다. 중심은 일반 입력 점과 별도입니다.

### 상태·이행·복원 검증

- 스키마 **6**. 기존 1~5 이행을 유지하고 `analysisConfigs` 키를 `JSON.stringify([datasetId, kind])`로 바꿉니다. 회귀·군집 설정을 독립 보존합니다. 기존 회귀 결과·그래프·가공 기록은 재작성하지 않습니다. 구형 군집의 상세 계산 자료가 없으면 조회 제한을 안내하며 중심/라벨/지표를 채우지 않습니다.
- 군집 현재/비교 선택, 표시 축을 별도 화면 상태로 저장합니다. 종류가 다른 결과를 회귀 목록이나 교차 지표 비교에 넣지 않습니다. 원본·기존 버전·완료 결과와 조건 스냅샷은 보존합니다.
- Worker 전용 `clustering-run` / `clustering-detail` 메시지. 조건/자료 변경, 취소, 프로젝트 전환·삭제·초기화·복원 시 기존 gate와 Worker 종료로 이전 응답을 차단합니다. 반영 전에 프로젝트·현재 조건·기록 ID를 재확인합니다. 메뉴 이동은 취소가 아닙니다. 취소한 k 비교의 부분 결과는 저장하지 않습니다.
- 복원은 자료/버전/열/행·범위, 수치 의미·차원 순서, 결측/스케일 기준, seed/k/초기화/종료, 중심·라벨·구성원 수, 각 행 거리·SSE, 반복 평균·변화 수·이동량, 수렴/최종 재할당, 표본 참조·실루엣 값, 선택/비교/해석 참조와 한도를 검사합니다. **K-means를 재실행하지 않고 저장된 중심에 대한 거리·평균·지표를 확인**합니다. pending/running은 중단 처리하며 자동 재개하지 않습니다. 손상은 프로젝트 교체 전에 거부합니다.
- 읽기 전용 탭은 기존 잠금과 전체 작업 보호를 유지합니다. 영속 설정 변경·실험 저장·기록 삭제를 차단합니다. 새 Worker·그래프 청크도 기존 precache와 저장 후 선택적 업데이트에 포함됩니다.

### 성능 한도

학교 PC에서 단일 작업·복원·JSON 복사 메모리와 응답성을 제한하기 위한 상한이며 실행 시간을 보장하는 수치는 아닙니다.

| 항목 | 상한 |
|---|---|
| 실제 군집 입력 | 20,000행 × 20개 계산 특성 |
| k / 한 실행의 k 목록 | 1~20 / 최대 8개 |
| 재시작 / 최대 반복 | 1~10 / 1~100 |
| 보수적 군집 거리 좌표 연산 | N×D×Σk×재시작×(3×최대반복+3) ≤ 1.2억 |
| 실루엣 거리 좌표 연산 | N×평가점수×D×k비교개수 ≤ 2,000만 |
| 실루엣 평가 표본 | 최대 1,000점, 사용자가 지정 |
| 중심 이력 좌표 | 2×D×Σk×재시작×(최대반복+1) ≤ 160,000 |
| 결과 직렬화 크기 | 실행당 UTF-8 JSON 12 MiB |
| 프로젝트 | 분석 기록 총 50개, 군집 검증 추정 좌표 연산 2.4억 |
| 화면 | 표시점 최대 1,000, 행 표 25개/페이지, 직접 실험 최대 300점 |

한도 초과는 범위·속성·k·반복·재시작·실루엣 표본을 줄이도록 안내합니다. 원본 행을 조용히 자르지 않습니다. 입력·저장 기존 20MB/50,000행/500,000셀·보존 300만 셀·복원 80MiB 한도도 함께 적용됩니다.

- **취소:** 10,000행·8차원 계산의 **`k=2 · seed=42 · 1/50회 할당·평균 갱신 중`**에서 취소하여 취소 기록으로 남는 것을 확인했습니다. 완료 후 취소한 사례가 아닙니다. 별도 실행에서는 계산 중 시각화→결과 메뉴 이동 후 계산이 계속됐고, 다시 실행한 작업의 전처리 중 seed를 바꾸자 조건 변경 취소가 기록됐습니다. 기존 완료 결과는 남았습니다. 프로젝트 누적 검증 한도도 새 기록 생성 전에 차단됐습니다.
- **저장·복원:** 새로고침, 저장 후 선택적 업데이트, 실제 JSON 다운로드·검증·새 프로젝트 사본 복원(자료 4개·보존 버전 5개·작업 5개), 회귀 실행 후 군집↔회귀 설정·목록 분리를 확인했습니다. 복원 시 K-means를 자동 실행하지 않았습니다.
- **읽기 전용·화면:** 두 번째 탭에서 군집 실행·영속 설정·삭제가 비활성화됨을 확인했습니다. 390×844에서 실제 문서 폭 375px/스크롤 폭 375px로 페이지 가로 넘침이 없었고, 키보드로 설정 초점 이동(`cluster-settings`)과 실행을 확인했습니다. 표 내부는 가로 스크롤을 사용합니다. 화면: `docs/stage8-desktop.jpg`, `docs/stage8-mobile.jpg`.
- **오프라인:** 해당 검증 서버 프로세스를 확인하고 중지한 후 페이지를 다시 열었습니다. 새 군집 기록(11:27:30)이 완료됐으며 반복 단계·점별 중심 거리·실루엣 a/b·분포 표도 조회됐습니다. 콘솔 오류는 없었습니다. 검증 후 **4198 서버를 다시 실행**했습니다.
- **당시 미검증/지원 제한:** 실제 터치 기기와 스크린리더, 다른 브라우저·학교 PC의 실측 성능, 공개 GitHub Pages 배포는 검증하지 않았습니다. 좌표 이동은 입력 표로 제공하며 포인터 드래그·과정 자동 재생은 제공하지 않습니다. 연관 규칙은 아래 9단계에서 추가했습니다.

## 9단계 — 연관 규칙과 거래 근거 (v0.9.0)

### 실행과 사용 순서

검증 서버 주소는 **http://127.0.0.1:4200/** 입니다. 재실행:

```sh
npm run build
npm run serve:production -- 4200
```

1. 자료를 불러오고 **분석 또는 결과 → 분석 영역 → 연관 · 함께 나타나는 항목**을 선택합니다. 회귀·군집 설정과 기록은 별도로 유지됩니다.
2. 설정에서 거래 형식·열·범위·빈 거래/미등록 정책을 정하고 **거래 미리보기**를 누릅니다. 원자료 행 수, 범위 근거 행 수, 실제 거래 N, 항목 수, 빈 거래, 제외·반복 제거·병합 내역과 앞 25거래를 확인합니다.
3. 지지도·신뢰도는 백분율을 입력하고 각각 **적용**합니다. 미확정·잘못된 입력이 있으면 실행하지 않습니다. 최대 항목 집합 길이는 1~6이며 기본 4입니다. 길이 4부터 양쪽이 복합인 규칙을 만들 수 있습니다.
4. **연관 분석 실행**으로 새 기록을 만듭니다. 계산은 Worker에서 진행하며 메뉴 이동 중 계속됩니다. 취소 또는 입력 조건 변경 시 해당 Worker와 작업 ID를 무효화합니다. 완료 전 부분 결과는 보존하지 않습니다.
5. 규칙의 선행·후행 이름 검색과 항목 선택(모두/하나 이상), 지표 정렬, 25개 페이지로 결과를 탐색합니다. 규칙을 선택하면 분자·분모, 2×2 거래 수, 모든 항목을 포함한 실제 거래와 당시 버전의 원자료를 확인할 수 있습니다.

### 거래·항목·분모의 정의

| 형식 | 사용법과 거래 구성 |
|---|---|
| 한 행의 항목 목록 | 열을 선택하고 셀 내부 구분 기호로 나누거나 각 셀을 항목 하나로 사용합니다. 큰따옴표 안 구분자·줄바꿈, 두 번 쓴 따옴표를 지원합니다. 파일 CSV 구분자와 별개입니다. 한 행이 한 거래입니다. |
| 거래 ID·항목의 세로 자료 | 거래 ID 열과 항목 열을 하나씩 지정합니다. 실제 자료형까지 같은 ID끼리 묶습니다. 필터/선택 행은 거래 ID를 찾는 근거이며, 선택된 ID의 **같은 버전 전체 행**으로 완전한 거래를 구성합니다. |
| 항목별 선택 여부 표 | 항목 열을 여러 개 고르고 선택/미선택 값을 JSON 배열로 명시합니다. 기본 선택 `[true,1,"1"]`, 미선택 `[false,0,"0"]`이며 실제 자료형을 구분합니다. 임의의 truthy 판정이나 미선택 항목 생성은 없습니다. |
| 범주 속성 표 | 범주·식별자 등 열의 `속성=값`을 항목으로 씁니다. 열 ID를 포함하므로 같은 값·같은 열 이름이어도 다른 속성과 섞이지 않습니다. 수치·날짜 의미 열은 자동 구간화하지 않고 거부합니다. |

- 숫자 `1`, 문자열 `"1"`, `"001"`, 불리언은 다른 값입니다. 항목 ID는 자료·열 ID·값의 자료형과 값으로 구성하며 화면 배열 위치나 표시 이름에 의존하지 않습니다. 목록 방식은 선택한 열들이 하나의 항목 공간을 공유합니다.
- 목록의 빈 셀·빈 목록은 **알려진 빈 거래**입니다. 기본은 N에 포함하며 제외를 명시적으로 선택할 수 있습니다. `NA`, `0`, `false`는 임의의 결측이 아닙니다. 공백 제거·대소문자 통합은 사용자가 선택할 때만 적용하고 병합 전 값을 기록합니다.
- 선택 여부의 미등록 값·범주 결측·세로 자료의 알 수 없는 항목은 기본 차단합니다. 거래 제외 또는 명시적 미선택 취급을 선택할 수 있고 근거를 남깁니다. 결측 거래 ID는 별도로 차단/제외하며 하나의 가짜 ID로 합치지 않습니다. 세로 거래 제외는 해당 ID의 전체 거래에 적용합니다.
- 같은 거래 안의 반복 항목은 한 번 셉니다. 서로 다른 행/ID의 동일한 항목 목록은 **각각 별도 거래**입니다. 빈 거래 정책까지 적용한 실제 N을 모든 규칙의 공통 분모로 사용합니다. N=0은 오류이며 N>0에서 규칙 0개는 정상 완료입니다.
- 정렬·페이지는 계산 범위에 영향을 주지 않습니다. 전체/현재 필터/선택 행 범위를 스냅샷으로 보존하며 빈 선택을 전체 자료로 바꾸지 않습니다. 변환은 분석 전용이고 자료 버전·원본·작업 기록을 수정하지 않습니다.

### 계산 규칙 `apriori-1`

외부 계산 의존성을 추가하지 않은 TypeScript 구현입니다. 후보 결합·부분집합 가지치기는 [Agrawal·Srikant의 Apriori 원 논문](https://vldb.org/conf/1994/P487.PDF), 지표 정의는 [arules 설명 논문](https://journal.r-project.org/articles/RJ-2017-047/)을 확인했습니다. 런타임 서버나 CDN에서 계산 코드를 가져오지 않습니다.

- 길이별 이전 빈발 집합의 같은 접두사를 결합하고, 모든 직전 길이 부분집합이 빈발인지 검사합니다. 가지치기하지 않은 후보는 항목별 거래 인덱스로 정확히 셉니다. 실제 생성·가지치기·계수·빈발 수와 각 후보를 저장합니다. 가지치기한 후보의 미계산 빈도는 `null`입니다.
- 최소 지지도 s에 대해 `ceil(N × s / 100)`건 이상을 채택합니다. 입력은 소수 8자리까지의 십진 문자열로 보존하고 BigInt 정수 비율로 임계값을 비교하므로 화면의 반올림과 무관합니다. 지지도는 0 초과~100%, 신뢰도는 0~100%입니다.
- 각 빈발 집합에서 비어 있지 않은 모든 진부분집합을 선행 A로, 나머지를 후행 B로 생성합니다. A와 B는 겹치지 않고 양쪽 복합·반대 방향도 포함합니다. 최대 길이는 `|A∪B|`이며 ID와 방향으로 중복을 제거합니다.
- 지지도 = `count(A∪B)/N`, 신뢰도 = `count(A∪B)/count(A)`, 향상도 = 신뢰도 / `(count(B)/N)`. 모든 계수와 N을 함께 저장합니다. 표시만 소수 6자리까지이며 NaN·Infinity를 저장하지 않습니다.
- 최대 길이 도달·빈발 집합 없음·다음 후보 없음 중 실제 종료 이유와 계산 범위를 표시합니다. 자동 임계값 변경·행 표본 추출·상위 규칙만 잘라 완료하기는 하지 않습니다. 규칙은 수량·순서·인과 효과를 뜻하지 않습니다.

### 결과 탐색·비교·저장

- 규칙 선택은 화면 상태입니다. 검색·정렬·페이지는 저장된 규칙을 조회하며 분석 조건이나 최신 여부를 바꾸지 않습니다. 동률은 항목 ID와 방향의 사전 순서입니다.
- 관련 거래는 둘 다/선행만/후행만/둘 다 아님/빈 거래/전체로 조회합니다. 복합 항목은 **해당 집합 전체를 포함**해야 충족합니다. 2×2 표는 이 기준을 동일하게 사용합니다. 원자료는 당시 버전·행 ID로 조회하고 현재 자료 버전을 바꾸지 않습니다.
- 두 실행은 실제 거래 모집단, 자료 버전, 항목·결측·빈 거래 정책, 최대 길이를 먼저 비교합니다. 공통·추가·제거 규칙과 지표를 표시하되 서로 다른 모집단을 같은 조건인 것처럼 취급하거나 자동 최적 기준을 고르지 않습니다.
- 당시 버전·조건으로 새 실행, 현재 버전으로 조건 복제를 구분합니다. 자료/조건 변경 후에도 과거 결과와 조건은 불변이며 재분석 필요 표시를 제공합니다.
- 스키마 **6**, 백업 형식 **1**을 유지하고 1~6 이행 경로에 선택적 연관 필드를 추가했습니다. 종류별 설정 키는 `[자료 ID, 분석 종류]`의 JSON 문자열입니다. 연관 현재/비교 선택과 기록별 조회 조건을 별도로 저장합니다. 기록 삭제 시 회귀·군집·연관의 선택/비교/조회/해석 참조를 정리합니다.
- 복원은 자료·버전·열·행·범위·형식·정책·거래 ID와 항목 대응, N·계수·임계값·지표, 저장한 후보 단계의 연결/가지치기/빈발 판정, 규칙의 방향·완전성·중복, 화면 참조를 검증합니다. **새 Apriori 탐색으로 결과를 생성하지 않습니다.** 고정 원자료에서 거래를 확인하고 저장된 후보·규칙의 근거를 제한된 계산량 안에서 검산합니다. 손상된 파일은 프로젝트 교체 전에 거부합니다.
- pending/running 기록은 복원 시 취소 상태로 이행하며 자동 재개하지 않습니다. 구형 상세 결과가 없는 기록은 조회 제한을 안내합니다. 읽기 전용 탭에서는 결과 검색·상세 조회는 허용하고 실행·조건 저장·삭제는 차단합니다.

### 성능 한도

상한은 메모리·복원 비용을 제한하기 위한 것으로 다른 학교 PC에서의 실행 시간을 보장하지 않습니다. 후보·규칙 한도는 생성 중에 검사하고 초과하면 원인과 줄일 조건을 안내합니다.

| 항목 | 상한 |
|---|---|
| 원자료 / 실제 거래 | 각각 20,000 |
| 서로 다른 항목 / 거래당 항목 | 128 / 32 |
| 최대 집합 길이 | 6 |
| 생성 후보 / 저장 규칙 | 전체 12,000 / 30,000 |
| 후보 결합 시도 / 규칙 조합 | 2,000,000 / 100,000 |
| 후보 계수 및 상세 조회 방문 | 30,000,000 |
| 거래 인덱스 항목 수 | 640,000 |
| 목록 셀 / 개별 문자열 항목 | 65,536 / 512 문자 |
| 변환 거래 및 결과·과정 직렬화 | 각각 UTF-8 JSON 12 MiB |
| 프로젝트 누적 연관 복원 검증 추정량 | 90,000,000 (원자료×32 + 저장 후보×N×길이 + 규칙×6) |
| 프로젝트 분석 기록 | 모든 종류 합계 50개 |
| 거래·규칙·후보·당시 원자료 표 | 25개/페이지 |

기존 파일 입력·프로젝트 저장 한도도 적용됩니다. 누적 복원 예산을 넘으면 새 완료 결과의 저장을 차단하고 기존 완료 결과는 유지합니다. 미리보기와 계산은 별도 작업이며 미리보기 후 설정 변경 시 다시 확인해야 합니다.

### 9단계 검증 기록 (2026-10-16)

- **자동 검증:** 15개 파일·250개 테스트 통과(기존 196개 + 연관 54개). 네 형식, 따옴표·한글·타입·앞자리 0·동명이열·빈 거래/미등록 정책, 완전한 세로 거래, 정확 임계값·복합 양방향 규칙·가지치기·한도, 검색 모두/하나 이상·페이지·정렬 독립성, 불변 스냅샷·최신 여부·비교·손상 복원 거부·모든 종류 삭제 참조·늦은 응답 차단을 다룹니다.
- **독립 정답:** `{A,B,C,D}` 2개, `{A,B,C}` 1개, `{A}` 1개, 빈 거래 2개에서 N=6. `{A,B}→{C,D}`는 지지도 2/6·신뢰도 2/3·향상도 2, 역방향은 2/6·1·2, 2×2는 2/1/0/3입니다. 7%×100거래 경계와 소수 신뢰도 경계도 검증합니다.
- **실제 브라우저(IAB):** 네 형식 CSV 입력·미리보기·완료, 복합 규칙과 근거/원자료, 30%/50%의 50규칙과 30%/100%의 28규칙 비교, 100%/100%의 정상 0규칙, 검색·정렬·빈 거래, 잘못된 임계값/미등록 값/33항목 한도 안내를 확인했습니다. 세로 자료는 선택 1행의 ID에 해당하는 4개 원자료 행이 모두 거래에 포함됐습니다.
